# Proyek Apktool Mousike v1.5.8 — code123

Direktori ini adalah hasil dekompilasi Apktool dari APK Mousike v1.5.8/code123. Kode aplikasi disajikan sebagai Smali bersama manifest dan resource hasil decode. Ini **bukan** source Kotlin/Gradle asli.

Proyek ini merepresentasikan APK yang sudah dirilis; `apktool.yml` mencatat `versionCode` 123 dan `versionName` 1.5.8. Untuk membangun kembali DEX dan mengemasnya ke APK dasar yang cocok, gunakan `scripts/build_release.sh` dari folder paket di atas. Keystore rilis tidak disertakan.

Skrip `scripts/apply_requested_patch.py` adalah utilitas opsional untuk menerapkan perubahan QRIS/branding tertentu ke proyek Apktool lain yang kompatibel. Skrip tersebut tidak diperlukan untuk membangun ulang proyek code123 ini.
